## 課題 1: Alpine Linux を起動してみる

`alpine` という超軽量 Linux イメージを使って、コンテナの中でコマンドを実行してみましょう。

**ヒント:** `docker run -it alpine sh` で起動できます。
- `-it` は「インタラクティブにターミナルを使う」オプションです
- `sh` はコンテナ起動後に実行するコマンドです

**やること:**
1. alpine コンテナを起動してシェルに入る
2. コンテナの中で `cat /etc/os-release` を実行してOSを確認する
3. `exit` でコンテナから出る

---

## 課題 2: コンテナのライフサイクルを確認する

1. nginx コンテナを `my-web` という名前でバックグラウンド起動する（ポート 8081:80）
2. `docker ps` で起動を確認する
3. `docker logs my-web` でログを確認する
4. `docker stop my-web` で停止する
5. `docker ps -a` で停止状態を確認する
6. `docker rm my-web` で削除する
7. `docker ps -a` で消えたことを確認する
